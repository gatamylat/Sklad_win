# Проверка заявки на складе Массивбург

Откройте **start.cmd** на Windows. Нужен Python 3.10 или новее с Tkinter. При первом запуске программа установит зависимости в `%LOCALAPPDATA%\Sklad_win\venv`.

1. Нажмите **+** и выберите одну или несколько Excel-заявок конструктора (`.xlsx` или `.xlsm`). Поддерживаются листы «Общая Мат», «Без пробелов», «Проверка» и другие листы с колонками количества и названия либо артикула. Для расчёта нужна единица измерения. Удалить заявку можно в меню имени файла.
2. Скачайте **Закупки → Файл → Скачать → Microsoft Excel**. Из **Сверки склад → Реестр** скачайте **реестр (json)**. Укажите оба файла один раз. При обновлении заменяйте выгрузки по тем же путям. Даты видны в окне проверки.
3. Для проверки спорных совпадений откройте **DeepSeek** и вставьте ключ через `Ctrl+V` или кнопку **Вставить**. Кнопка **Запомнить ключ** сохраняет его в диспетчере учётных данных Windows. Можно использовать переменную окружения `DEEPSEEK_API_KEY`.
4. Проверка запускается автоматически, как только указаны заявки и оба складских источника. Чтобы перечитать те же файлы, выберите **Меню → Проверить заявки** или нажмите `Ctrl+R`. Выберите позицию в таблице, чтобы справа увидеть количество по каждой заявке и данные из обоих источников.
5. **Выгрузить наличие** сохраняет найденные позиции, полки, количества по реестру и «Закупкам», итог к выдаче и закупке. **Полный отчёт** добавляет все позиции, подсказки и отдельный лист со строками исходных заявок. Даты источников сохраняются в обоих файлах.

**По реестру** показывает количество на полках, **Свободно** показывает остаток по «Закупкам», **Взять** показывает сколько можно рекомендовать к выдаче. Если в реестре есть позиция с пустым количеством, программа показывает «Не пересчитано» и адрес. Подтверждённые позиции с совместимыми единицами объединяются, остаток распределяется один раз на весь набор заявок. Свободный остаток берётся из K листа «Склад». В стандартных формулах бронь из J уже вычтена. Столбцы F, K и M листа «Счета» связывают наименование с артикулом и единицей измерения. Строки сметы с пустой ячейкой количества пропускаются.

Окно подстраивается под размер экрана и масштаб Windows. В шапке доступны **Масштаб** от 100 до 200 процентов и переключатель светлой и тёмной темы. Оба значения запоминаются. Заголовки используют Playfair Display 500, в латинских обозначениях используется DM Sans. Шрифты из папки `fonts` загружаются на время запуска программы, лицензии находятся рядом с ними.

DeepSeek сравнивает неполные совпадения. API получает описание, артикул и единицу измерения строки, а также несколько кандидатов. Решение о выдаче по подсказке или аналогу остаётся за проверяющим. При ошибке DeepSeek программа показывает причину, локальные результаты и найденных кандидатов.

Журналы проверок хранятся в `%LOCALAPPDATA%\Sklad_win\logs`. В каждом JSON указаны файлы и их даты, результат по строкам, основания расчёта и итог обращения к DeepSeek. Папка открывается из окна проверки.

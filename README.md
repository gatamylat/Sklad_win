# Проверка заявки на складе Массивбург

Откройте **start.cmd** на Windows. Нужен Python 3.10 или новее с Tkinter. При первом запуске программа установит зависимости в `%LOCALAPPDATA%\Sklad_win\venv`.

1. Возьмите Excel-заявку у конструктора и выберите её в первом поле (`.xlsx` или `.xlsm`). Поддерживаются листы «Общая Мат», «Без пробелов», «Проверка» и другие листы с колонками количества и названия либо артикула. Для расчёта нужна единица измерения.
2. Скачайте **Закупки → Файл → Скачать → Microsoft Excel**. Из **Сверки склад → Реестр** скачайте **реестр (json)**. Укажите оба файла один раз. При обновлении заменяйте выгрузки по тем же путям. Даты видны в окне проверки.
3. Скопируйте ключ DeepSeek и нажмите **Вставить** или `Ctrl+V` в поле ключа. Кнопка **Запомнить ключ** сохраняет его в диспетчере учётных данных Windows. Можно использовать переменную окружения `DEEPSEEK_API_KEY`.
4. Нажмите **Проверить заявку**. Найденные позиции открываются сразу. Через поиск можно найти строку по полке, названию или артикулу. Выберите позицию, чтобы увидеть данные из обоих источников.
5. **Выгрузить наличие** сохраняет в Excel найденные позиции, номера строк заявки, полки, количество в реестре и свободный остаток по «Закупкам». **Полный отчёт** добавляет лист со всеми строками и подсказками. Даты источников сохраняются в обоих файлах.

**По реестру** показывает количество на полках, **Свободно** показывает остаток по «Закупкам», **Взять** показывает сколько можно рекомендовать к выдаче. Если в реестре есть позиция с пустым количеством, программа показывает «Не пересчитано» и адрес. Подтверждённое количество распределяется один раз в пределах заявки. Свободный остаток берётся из K листа «Склад». В стандартных формулах бронь из J уже вычтена. Столбцы F, K и M листа «Счета» связывают наименование с артикулом и единицей измерения. Строки сметы с пустой ячейкой количества пропускаются.

Окно подстраивается под размер экрана и масштаб Windows. Регулятор **Масштаб** позволяет изменить размер шрифтов и строк от 100 до 200 процентов. Выбранный масштаб запоминается.

DeepSeek сравнивает неполные совпадения. API получает описание, артикул и единицу измерения строки, а также несколько кандидатов. Решение о выдаче по подсказке или аналогу остаётся за проверяющим. При ошибке DeepSeek программа показывает причину, локальные результаты и найденных кандидатов.

Журналы проверок хранятся в `%LOCALAPPDATA%\Sklad_win\logs`. В каждом JSON указаны файлы и их даты, результат по строкам, основания расчёта и итог обращения к DeepSeek. Папка открывается из окна проверки.
